# Neon Race

Neon Race is a browser-based arcade game built with HTML5 Canvas and JavaScript.

The player controls a small spacecraft while navigating through an increasingly dangerous asteroid field. The game features neon-inspired visuals, power-ups, shooting mechanics, dynamic effects, and increasing difficulty.

## Features

- Neon-inspired arcade visuals
- Dynamic asteroid spawning
- Increasing difficulty over time
- Player movement and collision detection
- Score and survival timer
- Shield power-up
- Slow-motion power-up
- Automatic shooting power-up
- Projectile and asteroid collision system
- Pause and restart functionality
- Background music and visual effects

## Controls

- **Arrow Keys** — Move the spacecraft
- **Esc** — Pause / resume the game

Shooting is activated automatically when the shooting power-up is collected.

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas

## Running the Project

No installation or build process is required.

For the best experience, run the project with a local development server such as the **Live Server** extension in Visual Studio Code.

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Start Live Server.
5. Play in your browser.
